## 🎯 Objective
The objective of this lab is to learn and practice NumPy for numerical computing, array manipulation, mathematical operations, data analysis, and basic image processing using Python.

## 🛠️ Tools & Technologies
- Python 3
- NumPy
- Jupyter Notebook
- Miniconda

## 📚 Lab Tasks

This lab consists of the following 11 tasks:

1. **Task 01 – Setup:** Import NumPy and check its version.
2. **Task 02 – Creating Arrays:** Create and initialize NumPy arrays.
3. **Task 03 – Randomness and Reproducibility:** Generate random numbers and simulate dice rolls.
4. **Task 04 – Spacing and Reshaping:** Create arrays, generate equally spaced values, and reshape data.
5. **Task 05 – Indexing and Slicing:** Perform array indexing and slicing operations.
6. **Task 06 – Census 2023:** Analyze population data of Pakistan's administrative units.
7. **Task 07 – Climate Analysis:** Analyze temperature and rainfall data of five cities.
8. **Task 08 – Inflation Analysis:** Compare FY2024 and FY2025 inflation data.
9. **Task 09 – Grace Marks:** Apply grace marks and calculate student performance statistics.
10. **Task 10 – Image Processing:** Create, flip, invert, crop, and brighten an image using NumPy arrays.
11. **Task 11 – Reflection:** Summarize learning outcomes and findings.

## 📊 Datasets Used
- **Census Data:** Pakistan Bureau of Statistics – Population Census 2023.
- **Climate Data:** PMD / WMO climate normals (1991–2020).
- **Inflation Data:** Pakistan Economic Survey 2024–25, Chapter 7.
- **Marks Data:** Sample lab-section student marks.
