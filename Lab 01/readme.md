## 🎯 Lab Objectives

- Python 3
- Jupyter Notebook
- Miniconda

## 📚 Lab Tasks

This lab consists of 10 practical tasks:

| Task | Topic | Description |
|---|---|---|
| 01 | Exponentiation Operator | Calculate powers using Python operators. |
| 02 | String Splitting | Split a sentence into individual words. |
| 03 | String Formatting | Display formatted output using `format()`. |
| 04 | Nested List | Access elements from a nested list. |
| 05 | Nested Dictionary | Access values from a nested dictionary. |
| 06 | Lists vs. Tuples | Understand mutable and immutable data structures. |
| 07 | Email Domain Extraction | Extract a domain from an email address. |
| 08 | Checking for Dog | Check whether a string contains the word "dog". |
| 09 | Counting Dog Occurrences | Count occurrences of "dog" regardless of capitalization. |
| 10 | Speeding Ticket Calculator | Apply conditional statements to calculate speeding tickets. |
